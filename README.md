## Introduction

**Aleo** is a platform for fully private, programmable applications using zero-knowledge proofs. This repository is a *community-driven* collection of resources, libraries, and ecosystem projects showcasing what’s possible in the Aleo ecosystem. Whether you’re a developer, researcher, or just curious about zero-knowledge cryptography, you’ll find plenty of projects here to explore and learn from.

**Want to add your project?** Check out our [CONTRIBUTING.md](./CONTRIBUTING.md) for guidelines on how to submit a pull request.
