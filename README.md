## Introduction

**Aleo** is a platform for fully private, programmable applications using zero-knowledge proofs. This repository is a *community-driven* collection of resources, libraries, and projects showcasing what’s possible in the Aleo ecosystem. Whether you’re a developer, researcher, or just curious about ZK cryptography, we’ve got you covered!  

:fire: **Pro tip:** Want to add your project? Check out our [CONTRIBUTING.md](./CONTRIBUTING.md) for how to submit a pull request.
