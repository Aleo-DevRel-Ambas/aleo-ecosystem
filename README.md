## 🤝 How to Contribute

*Contributions are reviewed on a rolling basis. Please allow some time for maintainers to evaluate your submission.*

Want to contribute? Follow these steps:
1. **Fork the repository.**
2. **Submit your changes** via a Pull Request.
3. **Ensure your changes align** with the repository structure.
4. **Follow the contribution guide** [here](./CONTRIBUTING.md).

✅ We are looking for:
- New Aleo ecosystem projects.
- Useful developer tools.
- Research papers and technical documentation.
